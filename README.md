# EHR studies

Manual modeling in RDF of some results of EHR studies, to populate the [PGxLOD](https://pgxlod.loria.fr/) knowledge graph.

A full description of the motivation, implementation and instantiation of PGxLOD is available in [2].

When citing PGxLOD, please use [2].
